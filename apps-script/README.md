# 방명록 · 참석 회신 연결 방법

GitHub Pages는 파일을 보여주기만 해서 하객이 쓴 글을 저장할 수 없습니다.
그래서 무료인 Google Apps Script를 저장 창구로 씁니다.

- 방명록: 내 구글 드라이브의 `wedding-guestbook.json` 파일 하나에 저장 (DB 없음)
- 참석 회신: 내 구글 드라이브의 `청첩장 참석 회신` 시트에 한 줄씩 추가

## 설치 (10분)

1. https://script.google.com 에서 **새 프로젝트**를 만듭니다.
2. 기본 `Code.gs` 내용을 지우고 이 폴더의 `Code.gs`를 통째로 붙여넣은 뒤 저장합니다.
3. 위쪽 함수 선택에서 `setup`을 고르고 **실행**합니다. 권한 승인 창이 뜨면 본인 계정으로 허용합니다.
   - 실행 로그에 JSON 파일과 시트 주소가 찍히면 성공입니다.
4. 오른쪽 위 **배포 → 새 배포** → 유형 **웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**
5. 배포 후 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.
6. `design4-duet.html` 아래쪽의 `api: ''` 에 그 주소를 넣고 푸시합니다.

```js
api: 'https://script.google.com/macros/s/XXXX/exec',
```

## 관리

- 부적절한 글은 드라이브에서 `wedding-guestbook.json`을 열어 해당 항목을 지우면 됩니다.
- 하객은 작성할 때 정한 비밀번호로 본인 글을 지울 수 있습니다. 비밀번호는 암호화(해시)되어 저장됩니다.
- `Code.gs`를 고친 뒤에는 **배포 → 배포 관리 → 수정 → 새 버전**으로 다시 배포해야 반영됩니다. (URL은 그대로)
- 결혼식이 끝나면 JSON 파일을 내려받아 저장소의 `data/guestbook.json`에 덮어쓰고 `api`를 비우면, 서버 없이 기념용으로 계속 볼 수 있습니다.
